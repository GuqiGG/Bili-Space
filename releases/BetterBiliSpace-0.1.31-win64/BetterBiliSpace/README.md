## 熟悉的播放，更好的外壳

保留官网登录、弹幕和播放器，搭配简洁的原生桌面外壳。没有 Electron，也不重新发明不兼容的播放体验。

| 观看 | 个性化 | 随时回来 |
| --- | --- | --- |
| Anime4K GPU 超分 / RIFE 光流补帧 | 深浅主题、顶部栏、分区选择 | 托盘双击唤起 |
| 无标题栏画中画 | 自由缩放与紧凑布局 | 关闭驻留、右键退出 |
| 推广清理、首页一键拉黑 | 进度条与播放栏融合 | 重复启动唤起已有窗口 |

## 开始使用

在 Releases 下载 Windows x64 包，**完整解压**后运行 `BetterBiliSpace.exe`。需要 Microsoft Edge WebView2 Evergreen Runtime。不要只复制 EXE；模型、资源和 DLL 需要一同保留。

- 关闭主窗口驻留系统托盘，双击打开，右键退出；没有设置开机自启。
- AI 视频帧本地处理，不上传。需要 WebGPU，60/120 fps 是呈现目标，不是性能保证；运动遮挡可能产生伪影，不可用时恢复原始播放。
- 线程撕裂者保留引擎，关闭浮动小球；一键拉黑仅保留首页功能。
- 可选 Mihomo 代理默认关闭。不保证免费候选可信或能观看地区限定番剧，建议使用自己的可信节点；不修改系统代理。

## 0.1.8 播放增强修订

超分使用 Anime4K WebGPU CNN（性能 CNNx2M / 质量 CNNx2UL），不是 Kazumi 的 mpv 后端。补帧从原始视频取帧，再将合成帧交给 GPU 超分，取消旧 CPU ×3 像素重建链路。补帧按源时间戳呈现，约33ms缓冲加推理开销；实际稳定性仍需要真实站点长时间验证。

## 0.1.9 补帧时序候选修订

补帧按固定短缓冲和有界完成队列呈现；仅显示原帧和 RIFE 真实中点，不再将中点光流近似为任意时刻。30fps源的AI ×2为60个不同画面，120Hz只代表显示目标。此修订仍需真实网站复测，不保证所有视频无抖动。

[通用超分模型调研（未接入）](docs/GENERAL-SR-MODELS.md)：优先比较 realesr-general-x4v3，不将 Anime4K 当作真人/游戏内容的通用默认。

## 0.1.10 剪贴板与简介链接

客户端运行时监听新复制的 BV 号或 bilibili.com/video 链接并跳转，保留数字 t / p 参数；不读取启动前的剪贴板，不记录内容，不主动弹出窗口。设置 → 外观可关闭。简介里的 HTTP(S) 链接变蓝，点击交给系统默认浏览器；只修复明确属于 lanzou[a-z]?.com 域名中的中文/表情干扰，保留其他文字、表情和正常国际化域名。不猜测 ASCII 字母干扰或任意网站真实地址，不自动访问提取出的链接。

## 0.1.11 通用域名干扰清理

简介链接清理不再限于蓝奏：域名中混入中文或表情时，若移除后仍是完整 ASCII 域名则生成清理后的蓝色链接。纯中文域名、路径/参数的中文和链接外表情保留；混合文字真实国际域名与人为干扰无法完全自动区分，请核对显示的目标域名。ASCII 字母干扰和路径干扰不猜测删除。

## 0.1.12 视频页窄窗自适应

覆盖视频主容器的固定/最小宽度和居中偏移；宽窗保留两栏，1060 CSS px及以下右栏移动到播放器下方；播放器、标题、简介随内容列收缩。修正首页按钮插入主容器产生隐式网格格位的问题。已在一个真实公开视频页的480/640/960/1060/1280/1920 CSS px视口检查边界，未覆盖所有网站变体与DPI组合。

## 0.1.13 实验入口收起与小电视过渡

播放栏不再显示超分/补帧入口；设置 → 播放保留测试选项、明确风险提示和画中画。升级第一次默认关闭已有实验开关，再开启会警告卡顿/闪烁/抖动风险。启动使用小电视旋转等待页，关闭用240ms缓入缓出旋转过渡，仍遵循托盘/退出设置；减少动态效果时不旋转。视频页首页按钮换成实心小电视。

## 0.1.15 缩放布局、加载过渡与音量

首页识别新版 bili-feed-card 包装层，缩放时重新排版，隐藏卡片和频道占位不再占格。进入视频立即显示小电视缓动加载页，页面/播放器元数据就绪后退场，未自动播放时可直接使用原生播放键；异常等待有显示页面入口。视频页顶部固定左上小电视＋首页，红绿灯移到右侧；不清理站点存储、不拦截空格/方向键/F/D/M/W等原生播放快捷键。关闭时窗口180ms快速收缩后遵循托盘/退出设置。

设置 → 播放新增100–200%音量增益，与原播放器音量叠加。先降低原音量，过度放大可能失真；受浏览器手势/CORS限制时不强接音频图，保留原声。使用真实 data-screen=mini 状态限制滚动预览为最高360px、16:9；WebView不透明主题底色和文档最早期底色减少切页白闪。

## 0.1.16 界面修整

- 视频页首页入口固定对齐；红绿灯以 240ms 曲线平滑移位，遵循减少动态效果设置。
- 导航期间原生深色遮罩衔接网页加载层；播放器准备到可显示画面后才退出。自动播放受限时可点击播放，也可选择显示原生页面。
- 悬停头像显示自己的昵称、等级、粉丝、关注及获赞；仅在悬停时请求统计，失败显示“—”。
- 已用独立测试配置和模拟账户数据验证；未访问你的私人登录资料，无法保证所有第三方页面切换场景均无闪白。

## 0.1.17 加载流程修复

- 顶部栏在文档创建阶段提前挂载，导航不再隐藏整个 WebView；视频遮罩仅覆盖内容区。
- 搜索使用搜索框进度提示，不再显示“视频加载中”。
- 视频加载按 BV / 分集去重，首帧完成后的媒体重载、清晰度切换不再反复唤起整页动画；切换其他视频或分集仍有一次加载过渡。

## 0.1.18 键盘焦点恢复

- 窗口重新激活或恢复原生焦点后，将键盘焦点交还 WebView，不再依赖额外鼠标点击。
- 使用程序化焦点恢复，不重设网页正在编辑的搜索框及光标；后台、最小化、隐藏及关闭过程中不抢焦点。
- 保留 WebView2 / Chromium，本版未迁移内核。

## 0.1.19 自动播放

- 移除加载层的“点击播放”和“显示页面”，进入视频后自动尝试播放，首帧就绪后自动退场。
- 本客户端进程启用 Chromium 无手势自动播放参数；不修改系统浏览器设置。
- 播放成功后的手动暂停不会被加载逻辑覆盖。播放失败或超时自动撤掉遮罩，让原生播放器展示错误，不再困在手动选择页。

## 0.1.20 搜索历史与官方联想

- 顶部搜索框新增历史记录，最多 20 条、自动去重，支持逐条删除和全部清空，重启后保留。仅保存在客户端本机设置文件，不同步修改 B 站账号的云端历史。
- 输入关键词后，“猜你想搜”从 B 站官方 `s.search.bilibili.com/main/suggest` 获取搜索联想；服务不可用时如实提示，不伪造推荐。
- 支持上下键选择、回车搜索、Escape 收起及中文输入法；适配深浅主题与窄窗口。输入关键词会发给 B 站以请求联想。

## 0.1.21 账户装扮与播放器

- 账户浮层显示当前账号的主页头图；保留接口返回的 GIF / WebP 等动态资源，MP4 / WebM 横幅静音循环，仅浮层展开时播放。获取失败不伪造背景。
- 顶部头像和浮层头像显示挂件，有效大会员显示官方角标与会员身份；过期不显示会员角标。
- 播放器原有画中画按钮接入客户端无边框小窗，支持从全屏进入。
- 原生音量滑条扩展至 0–200；100 以上通过本地 Web Audio 增益实现，不将 HTML 媒体音量写入非法的 2。过度增益可能失真；跨域音频不支持安全处理时仍保留原声。
- 装扮已使用模拟账户响应验证，未读取私人登录资料；实际显示取决于 B 站接口是否返回资源。

## 0.1.23 播放状态与顶部栏修复

- 关闭到托盘和托盘菜单隐藏会暂停媒体，恢复窗口保持暂停，不会擅自续播。

- 头像浮层轻弹进入，支持反向中断、键盘立即展开和减少动态效果。

## 0.1.24 输入快捷键与主页背景

- 搜索、评论、弹幕和可编辑区域输入时不触发外层播放器的空格、方向键等快捷键；保留文字编辑、中文输入法、光标移动及编辑器自身的发送处理。搜索 Shadow DOM 事件在本地处理，避免页面把它误认为播放器按键。
