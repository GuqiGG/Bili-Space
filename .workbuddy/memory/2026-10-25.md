# 2026-10-25

## 0.1.26 视频页下载 + 顶部/工具栏修复

- 顶部栏（关闭红绿灯时）：`.video-home-top` 改为流式布局排在最左，仍带 12px 分隔线；`[data-controls=windows][data-video=true]` 下隐藏导航里重复的「首页」；`.back`（分区箭头）order 从 1 改回 0，不再被挤到标题旁。
- 弹幕栏压住工具栏的根因：B站播放器按它自己算的列宽给 `#bilibili-player` 写固定像素高度，客户端自定义 grid 列宽后高度对不上，弹幕栏/点赞栏重叠或留大洞。修法：`alignVideoToolbar()` 实测 `.bpx-player-sending-area` 底边与 `.video-toolbar-container` 顶边的差，给工具栏写 margin-top 补偿（±480px 截断），路由/滚动/resize/loadedmetadata 触发，实测 1138–3021 宽度下 gap 归零。
- Bili23 Downloader 集成：原生 `downloader` 消息（status/open/browse/enable/download），走下载器自带的本地 MCP（127.0.0.1:23330，Bearer token 从 `%APPDATA%\Bili23 Downloader\config.json` 读），`initialize`→`parse_url`→`create_download`；worker 线程 + WM_APP+80 回传结果。视频页标题上方新增「下载」胶囊，和「首页」同排。
- 已验证：真实视频端到端建任务成功（临时下载目录，测完删除）；应用内「启用一键下载」能写 MCP 段并拉起下载器；105 个 node 测试全绿。
- 注意：测试时临时改过 Bili23 的 `download_path`，恢复时 `Download` 段其余键按官方默认值（4 线程/1 并发/1080P 优先/mp4）写回。用户若自定义过需自查。
