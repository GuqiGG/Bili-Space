# Better Bili Space：需求与决策记录
Date: 2026-10-24 · Goal: 完成第一版 Windows C++ B站客户端

## Summary / key decisions
- 用户要求专业美观的 C++ 客户端；保留正常观看、登录和弹幕。
- 集成 BTR；一键拉黑插件仅首页按钮，禁用该插件其他功能。
- 去除首页轮播、赛事推广、下载客户端；视频下方广告及右侧运营推广。
- 抖音美好体；左下角指定设置 SVG；顶部只留左侧红黄绿控件、首页右移。
- 图二频道区可在设置隐藏；进度条、主题高度自定义。
- 无标题栏画中画；超分入口在分辨率左侧，使用 sparkles.svg，性能/质量与倍率。
- 环境：空 Git 仓库、无 C++ 编译器；已安装 Edge WebView2 和抖音美好体。
- 技术建议：C++ Win32 + WebView2；工具链仅放本项目 .tools，不更改系统设置。
- 实现结果：已编译 Windows x64 客户端；7项 Node 测试通过，真实 C++/WebView2 冒烟测试通过。
- 真实海外首页 `/zh-Hans` 已观察到 10 个拉黑按钮（位于插件自有 ShadowRoot）；未点击任何拉黑按钮。
- GPU 测试观察到 640×360 -> 1280×720，另在匿名官网视频观察到 853×480 -> 1706×960，非 AI 超分。
- 画中画验证实际 HWND 无标题栏且置顶，BTR 悬浮球已隐藏；复用同一窗口，不是双窗口浏览模式。
- 原插件原始字节保留；已完成 BASELINE / MODIFIED / ROLLBACK 及字节级补丁重建。
- 本地检索索引：notes/INDEX.md；未向远程检索系统入库。
