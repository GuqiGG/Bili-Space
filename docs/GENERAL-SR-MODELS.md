# 通用视频超分候选（2026-10-25）

本表是上游资料筛选，不代表已经接入客户端或达到实时性能。

| 模型 | 内容与取舍 | 本项目状态 |
| --- | --- | --- |
| realesr-general-x4v3 | 官方通用场景轻量 SRVGG 模型；固定 x4 推理后可重采样，去噪去模糊能力有限 | 优先候选，未接入、未测 WebGPU 性能 |
| RealESRGAN_x4plus | 官方通用图像 x4 RRDB 模型；需要另测视频连续帧的细节稳定性及成本 | 质量比较候选，未接入 |
| SwinIR real_sr | 官方真实图像超分任务模型；不同配置不能混为一个模型 | 质量比较候选，未接入 |
| Anime4K CNN | 动漫侧的现有实时路径，不应作为所有内容默认方案 | 已有，实现不能等同 Kazumi 的 mpv 后端 |

来源：
- https://github.com/xinntao/Real-ESRGAN/blob/master/docs/model_zoo.md
- https://github.com/xinntao/Real-ESRGAN
- https://github.com/JingyunLiang/SwinIR

准入：上游权重与许可可核验，导出后 RGB/范围/色彩一致；真人、游戏、风景、字幕分别测试；720p/1080p 记录延迟、显存、实际处理帧率；连续视频比较亮度和纹理稳定性。60/120Hz 界面选项不构成模型性能保证。逐帧图像超分也可能产生时间不一致，不能只看截图。

本轮补帧修订：有界完成队列按源时间呈现；只显示模型真实中点及原帧，不继续用单份中点光流近似任意时刻。30fps 源的真实 x2 中点为60个不同画面，120Hz仅重复呈现，不宣称120个不同画面。
