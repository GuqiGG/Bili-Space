# Bili-Space 0.1.49 本地修复

- 默认在消息左侧显示收藏夹；支持目录切换、视频列表、分页与官方完整页面入口。
- 输入时只显示官方联想，清空后显示搜索历史；增加备用官方接口与一分钟内存缓存。
- 调整顶部操作、收藏面板、搜索下拉和个性化设置的颜色、间距与状态反馈。
- 启动时检查数据目录写入权限。不可写时复制可用资料至程序旁 `.userdata`，保留原目录；关闭 WebView2 初始化失败时静默退出的路径。
- 新数据目录不会包含在 ZIP 或安装包内。移动程序时应保留 `.userdata` 以保留本地恢复后的状态。

验证：233 项 Node 测试；普通模式真实 B站启动；登录状态与收藏目录读取；官方联想 200/8 条建议/输入时 0 条历史；桌面界面截图检查。
