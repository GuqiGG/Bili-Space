# Bili-Space 0.1.49

- 顶部新增独立返回按钮；窗口控制常显，默认窗口加大，减少切页时重复布局计算。
- Logo 移到左上角，默认只在首页显示；投稿改为左下角粉色加号，仅首页显示，与设置按钮处于同一界面层级，并保留个性化开关。
- 个性化整合顶部栏和进度条设置，可设置首页每行 2–8 个视频。
- 默认在消息按钮左侧显示收藏夹：紧凑双列面板，支持切换收藏目录、视频跳转和加载更多。
- 搜索框有输入时只显示官方联想；清空后显示搜索历史。增加备用官方接口和短期内存缓存。
- 修复卡片复用后的广告隐藏标记残留，暂时停用客户端弹幕增强，保留官方播放器弹幕和观看记录。
- 修复应用数据目录不可写时启动直接退出的问题：保留原目录，复制可用设置和浏览器资料到程序旁 `.userdata`；浏览器初始化失败时显示明确提示。

## 安装

安装版运行 Setup；便携版完整解压 ZIP 后运行 Bili-Space.exe。覆盖安装前从托盘退出旧版。
若程序已启用本地恢复目录，请保留程序旁 `.userdata`，其中保存恢复后的登录和设置；发行包不包含用户资料。
