# 公告接口 · bili.gvqi.top/news

客户端启动约 5 秒后请求一次 `GET https://bili.gvqi.top/news`，之后每 3 小时再请求一次（10 分钟内最多一次）。返回 200 和下面的 JSON 就会自动发放；返回其他状态码或内容不合法时，什么都不显示。

```json
{
  "items": [
    {
      "id": "2026-11-12-maintenance",
      "title": "服务器维护通知",
      "text": "今晚 23:00–23:30 反馈服务器维护。\n感谢支持！",
      "link": { "url": "https://bili.gvqi.top", "label": "打开官网" },
      "minVersion": "0.1.60",
      "maxVersion": "0.1.99",
      "until": "2026-11-13",
      "platforms": ["windows", "macos", "linux", "android"]
    }
  ]
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 字母、数字、`.`、`_`、`-`，最长 64。每个 id 每位用户只显示一次，改内容要换新 id |
| `title` | 是 | 最长 80 字节 |
| `text` | 否 | 最长 1200 字节，`\n` 换行，按纯文本显示 |
| `link` | 否 | `url` 必须是 https；`label` 是按钮文字（默认「查看详情」），用默认浏览器打开 |
| `minVersion` / `maxVersion` | 否 | 只发给这个版本范围内的客户端（含两端） |
| `until` | 否 | `YYYY-MM-DD`，过了这天不再显示 |
| `platforms` | 否 | 只发给这些平台；不写就是全部 |

- 最多读取前 10 条，响应最大 256KB。
- 有多条没看过的公告时，关掉一条再显示下一条。
- 公告会等欢迎引导、更新公告、分享弹窗、设置和反馈窗口都关掉后才弹出。
- 撤回公告：从列表里删掉即可，还没看到的用户就不会再收到。
