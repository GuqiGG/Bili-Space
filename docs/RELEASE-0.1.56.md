# Bili-Space 0.1.56

这一版把顶栏做成了客户端自己的一层，常驻在页面上面：点导航、前进后退时顶栏立刻动，不再等新页面加载完，换页时顶栏也不会跟着卡顿或闪一下。视频栏、顶栏动画和弹性按钮也一起做了性能和手感上的打磨。

## 独立顶栏

- **按了就动**：顶栏不再跟着网页一起重新加载，点首页、动态、历史时下划线马上滑过去，返回按钮和导航在同一个动画里一起让位。
- **换页不卡**：页面在下面加载，顶栏在上面照常响应，动画跑在合成层上，不再被页面加载拖慢。
- 搜索历史、收藏夹、头像卡片、消息菜单、分区列表都可以盖在页面上正常点击。
- 点当前页刷新时，刷新图标转完一圈会自动变回文字。
- 分区栏用鼠标滚轮滚动时会顺滑地滑过去，不再一格一格地跳。
- 顶栏右侧图标统一成一套：书签样式的收藏夹、统一粗细的线条图标、带阴影的头像和圆角登录按钮。
- 顶栏动画后、换页或页面加载后 1.5 秒内不出现刷新按钮，避免误点。

## 视频栏

- **窗口最大化或全屏时**：视频栏收成底部中间的一条小岛，看视频时 2.5 秒后自动收成一条细线，不挡画面。
- 视频栏随窗口大小缩放，动画跟随屏幕刷新率，高刷屏上更顺。
- 鼠标放上去不再整体泛白，弹性也更收敛。
- 在首页按 Ctrl+T 会弹出"你已经在主页啦！"的提示。

## 其他

- **测试版弹性按钮**：改成更自然的弹簧曲线，只回弹两下；相邻按钮放大得比当前按钮小；搜索栏只轻微放大。
- WebGPU 画质增强库改为用到时才加载，打开每个页面都更快。
- 去掉播放器里的反馈按钮，Logo 调淡；去掉首页加载时的假卡片占位。
