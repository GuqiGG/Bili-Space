# Bili-Space 0.1.45

- 修复增强弹幕开启后原生弹幕仍然全屏的问题：视频识别成功即接管原生层，加载失败自动恢复；播放器后补的弹幕容器会被持续隐藏。
- 每秒最多显示上限放宽到 10000 条，设为 0 即关闭限制，设置项直接显示“不限”。
- 设置页签改为对话框内独立滚动，页签变多后仍能看到“关于与更新”。
- 弹幕状态栏显示已接管的原生层数量，接管是否生效一眼可见。

## 安装与更新

安装版：运行 Setup；便携版：完整解压 ZIP 后运行 Bili-Space.exe。已有版本可在客户端内检查更新、下载并安装重启。

0.1.38 的旧更新器存在退出竞态；若安装重启失败，请先从托盘退出客户端，再运行本版 Setup 覆盖原目录。登录和设置保存在用户数据目录。

## 验证范围

通过 221 项自动化回归、社区状态与 Windows 媒体集成的原生测试；构建产物内置新弹幕接管与页签滚动样式。
