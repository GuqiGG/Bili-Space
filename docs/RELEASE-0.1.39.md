# Bili-Space 0.1.38 Hotfix

面向 0.1.38 的修复版。内部版本号为 **0.1.39**，以兼容现有客户端的版本比较和软件内升级；不是覆盖原 38 包体。

## 修复

- 音视频任一轨道下载失败后立即停止另一轨道，避免长时间假死；保留已有目标文件并清理临时文件。
- 修复重新检查或重启客户端后，已下载并校验的更新包被忘记、必须重复下载。
- 视频仍在下载时不再直接退出并安装更新，避免丢失正在下载的任务。
- 修复较新的备用更新源覆盖网站强制更新要求的问题。
- 修复强制更新页面使用 data 文档时按钮消息被错误拦截，同时继续拒绝普通网页的消息。
- 修复搜索框第一次按上方向键选中倒数第二项，而不是最后一项。

## 验证与范围

全部现有自动回归测试及新增原生 HTTP、双轨失败、更新页来源、缓存恢复、搜索键盘测试。
保留登录与个性化数据；不修改用户真实登录资料。实验超分/补帧仍不作为稳定功能保证。

安装 0.1.38 的用户可在「客户端设置 → 关于」检查、下载，然后「安装并重启」。
