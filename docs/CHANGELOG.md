## 0.1.7 AI 光流补帧与 Bili space

- 修复网页层覆盖原生窗口边缘导致鼠标无法拖动大小：保留 Windows 非客户区缩放边框，WebView2 只覆盖客户区。保留无标题栏的红黄绿控制，全屏不预留边框。不再使用透明子窗口命中层。

- 顶部和首页季节横幅中的标识统一为 **Bili space**。
- 补帧从原来的简单混合替换为 **RIFE v4.9 神经网络中间光流 + 遮挡掩码**。在本机 WebGPU 推理，视频帧不上传；模型、来源和 MIT 许可随包提供。
- 参考本机 Lossless Scaling 的 `LSFGFlowScale` / `QueueTarget` 设置概念，提供 25 / 50 / 100% 光流规模，估计分辨率上限 640×384。低分辨率只用于估计运动，使用原始尺寸的两张图像进行最终重投影，不把整张画面降清晰度。没有复制或分发 Lossless Scaling 的专有 DLL / LSFG 模型。
- 模型预测中点的四通道光流和遮挡权重：中点与原始 RIFE 网络输出等价；其他显示时刻沿中点光流缩放并重新归一化掩码，并非每个显示时刻重新跑一次网络。可能在遮挡、极快运动、转场处产生伪影。
- 活跃推理 + 单个最新待处理帧对，避免无限排队。延迟约一帧队列加推理耗时；60 / 120fps 是呈现目标，不是对所有显卡的实时保证。状态显示实际估计尺寸、推理耗时及中间帧数。
- SR 与 RIFE 共用串行 GPU 推理队列，避免 ONNX Asyncify 后端并发进入产生内存 / 管线错误。不能推理、视频跨域受保护或 GPU 丢失时恢复原生播放，不静默回退成混合补帧。
- 本地 Lossless Scaling 文件只读参考的哈希记录在 `verification/lossless-reference.json`；模型等价性记录在 `verification/rife-flow-equivalence.json`。

## 0.1.6 自由缩放与融合播放栏

- 主窗口边缘 / 四角可调整大小，最小限制由 880×560 降为 480×320；画中画最小 160×90。设置面板可拖右下角缩放，小尺寸自动重排。
- 超分按钮与新增补帧按钮并排位于原生清晰度左侧，采样原版清晰度控件的字号、颜色、透明度及弹层背景 / 圆角。沿用原播放栏显隐，支持鼠标悬停、点击、键盘和 Esc，不另加独立悬浮条。
- 补帧使用用户提供的三帧 SVG。提供关闭 / 本地 GPU 快速混合、60 / 120fps 目标；目标不是实际帧率承诺，屏幕刷新率与源帧处理速度会限制输出。
- **当前补帧是相邻真实帧的 GPU 混合，不是 AI 光流或运动补偿**，约增加一个源帧延迟，快速运动可能重影。实测黑 / 白两帧的中间输出为 127 灰度，而不是复制原帧。
- 可先 AI 超分、再补帧，独立开关；关闭或 GPU 上下文丢失恢复原始画面，保留音轨、弹幕及官网控制逻辑。补帧同样不上传视频帧。

## 0.1.5 本地 AI、分区选择与客户端代理

- 隐藏页面最右侧滚动条和设置面板滚动条，不禁用滚动，不删除右侧推荐内容。鼠标滚轮增加 150ms 短惯性；小幅 / 高精度滚动保持原生，键盘、点击会立即取消惯性，系统减少动态效果时不叠加动画。

- 左上角小箭头改为几何居中的 SVG；点击展开期间隐藏首页/动态/历史，点击收回恢复。
- 设置新增分区勾选面板，支持推荐 8 个、全选、全不选，自动保存。
- 最大化 / 全屏按舒适内容宽度自动放大；可关闭或选 1100 / 1280 / 1440 / 1600 档位，手动缩放最高 200%。
- 线程撕裂者悬浮球关闭，迁移已有本地设置；引擎和客户端设置里的插件设置入口保留。
- 超分替换为真正的本地 **ESPCN ×3 + ONNX Runtime WebGPU**。模型和运行时均随包提供，帧不上传。2× 是 ×3 神经网络输出再重采样；1× 不运行推理。源上限 1080p、呈现上限约 420 万像素；实际显示无需放大时跳过。模型内部仍做原始源尺寸 ×3 推理，高分辨率可能较慢，不保证 30fps；界面显示实测耗时 / 帧率。GPU 或跨域帧不可用时恢复原始播放。
- 内置 **Mihomo v1.19.33（Clash 兼容）**。设置中启用 / 关闭（自动重启客户端），切换节点即时生效。仅监听本机、控制端口带口令、无 TUN / 系统代理修改，退出客户端结束内核。默认只代理 B站相关域名；可选择全客户端流量。
- 提供公开免费候选，**默认关闭**；来源 [Au1rxx/free-vpn-subscriptions](https://github.com/Au1rxx/free-vpn-subscriptions)。节点可能过期，运营者未经审计，匿名连通不代表隐私可信。启用前请自行判断，不推荐敏感账号流量走陌生代理。导入 Clash YAML / JSON 时读取其中 `proxies` 节点，不导入完整配置的脚本、规则或任意监听设置；仅有远程 providers 的订阅需先导出实际节点。
- **免费候选未验证可以播放大陆限定番剧**；海外出口不等于中国大陆出口，也不保证会员 / 版权内容可用。用户自己的可信回国节点可导入。
- 上游源码与许可：[Mihomo v1.19.33](https://github.com/MetaCubeX/mihomo/tree/v1.19.33) / GPL-3.0、[ONNX Runtime](https://github.com/microsoft/onnxruntime) / MIT、[ESPCN 模型](https://github.com/onnx/models/tree/main/validated/vision/super_resolution/sub_pixel_cnn_2016)。许可和来源哈希在 `vendor/`，内核在 `runtime/`。分发时遵守对应开源许可。

## 运行

双击 `dist/BetterBiliSpace.exe`。保留同目录的 `WebView2Loader.dll` 、`assets/` 与 `runtime/`，不要只移动 exe。

- Windows 10/11 x64；需要 Microsoft Edge WebView2 Evergreen Runtime。
- 已安装的抖音美好体使用其真实字体名称 **DouyinSans Bold / DOUYINSANSBOLD-GB**；不打包或再分发字体。
- 登录在 B站官方页面完成。Cookie、偏好及插件设置保存在 `%LOCALAPPDATA%/BetterBiliSpace/`，与系统浏览器相互独立。
- 左下角齿轮打开设置；`Ctrl+,` 同样可用。F5 刷新。

## 这一版

- 去掉操作系统标题栏；左上角红/黄/绿按钮关闭、最小化、最大化。拖动顶部空白区域移动窗口，边缘缩放。
- 使用两个用户提供的 SVG；左下角客户端设置，播放器分辨率左侧星光超分入口。
- 深色 / 浅色 / 跟随系统、强调色、界面缩放和字体开关。
- 进度条颜色、高度、圆角、拖动圆点、常显控制条；不替换原生拖动和时间预览。
- 首页频道区显隐；保留频道节点，按开关隐藏。
- 非破坏式广告隐藏：首页推广轮播、赛事与下载入口、视频下方横幅、视频右侧明确的广告/运营容器。根据广告标识与投放 URL，不把普通视频或评论里的“广告”字样当成广告。
- **Bilibili 线程撕裂者**：固定上游 2026.10.24.1，本地集成用户脚本及必要 GM 存储适配。BTR 自身设置可从客户端设置打开。开关后刷新生效。不绕过会员、地区限制或 DRM。
- **一键拉黑**：保留上游官方黑名单接口实现，仅首页推荐按钮；兼容 `/zh-Hans` 等海外首页及带语言前缀的 UP主页 URL。搜索页、视频页按钮、隐藏直播、插件广告过滤、插件菜单均禁用。广告由客户端自己的开关管理。
- **无标题栏画中画**：复用当前播放窗口，切换为置顶无边框小窗，不重新加载视频。只显示视频与悬停后的返回/暂停操作，隐藏 BTR 悬浮球。Esc 或右下角“返回”恢复窗口。**这一版不是同时保留主窗口浏览的双窗口 PiP。**
- **GPU 空间增强**：WebGL 实际读取解码帧，缩放并进行自适应边缘锐化；性能模式 5 采样 / 最高 30fps，质量模式 9 采样 / 最高 60fps。支持 1×锐化、2×、3×目标倍率。受 GPU 最大纹理尺寸及 4K 像素预算限制，显示真实输出尺寸和实际倍率。**不是 AI 模型超分、RTX VSR 或 AMD 驱动超分。**
- GPU 失效、跨域不可读、受保护视频或源尺寸超过预算时保留原生播放，并显示失败原因。

## 构建

本机没有现成 C++ 编译器，因此工具链只下载到项目 `.tools/`，不改系统 PATH、不安装全局编译环境。

```powershell
python scripts/bootstrap.py
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1
```

固定 Zig 0.13.0、WebView2 SDK 1.0.3537.50；下载文件检查固定 SHA256。也提供 CMake 配置，已有 MSVC/Clang + Windows SDK 时可以使用。WebView2 SDK 路径通过 `WEBVIEW2_SDK` 指定。

## 验证

```powershell
npm ci --ignore-scripts
npm test
python scripts/verify_transaction.py
python scripts/smoke.py
python scripts/regression_ui.py
```

- `npm test`：DOM 清理、正常内容保留、设置、字体配置、播放器控件位置、PiP 状态、GPU 不可用降级、增量广告，以及拉黑插件路由/UID 策略。
- `smoke.py`：**启动已编译 C++ exe**，用测试专用的 localhost CDP 接口验证 WebView2 真实渲染、BTR 启动、字体加载、设置原生落盘、GPU 输出帧、实际 HWND 无标题栏与置顶、GPU 上下文丢失降级及匿名官网首页按钮。测试模式使用 `dist/.appdata/`，不接触正式用户 Cookie。
- `regression_ui.py`：在原生 WebView2 内用明确标注的页面 DOM 样本与模拟登录接口，验证五类页面布局、头像、消息链接、红绿灯几何中心，以及真实 Enter 按键和原生搜索导航。**模拟头像不是你的账号头像，也不声称已验证你的登录态。**
- 正常启动**不开放调试端口**。测试模式 `--test` 会开放本机 9223 端口，勿在测试中登录真实账号。
- `verification/smoke.json` 保存观察值；PNG 是运行截图，本地 fixture 均明确标识，不冒充官网数据。
- `verification/VERIFICATION.txt` 是 JSON 格式证据账本；包含 BASELINE、MODIFIED、ROLLBACK 原始 stdout/stderr、退出码与哈希。
- `verification/blocker.home.patch` 是字节精确的 Git binary patch，保留原插件并扩展 UI/native 改动；`verification/ROLLBACK.sh TARGET_COPY` 恢复原插件，`verification/ROLLBACK.sh TARGET_COPY ui` / `native` 恢复 0.1.0 的界面/原生源码；`ui-v0.1.1` / `native-v0.1.1` 恢复本次修改前的 0.1.1。请只对副本使用。
- `third_party/` 中上游 checkout 未改动；`verification/blocker.original.user.js` 保存原始字节。项目自用适配在 `assets/blocker.home.user.js`。

真实账号登录、会员片源、账号拉黑写入及不同海外网络吞吐仍需用户环境验收；测试没有替用户执行拉黑。广告规则依赖网站 DOM，网站更新后可能需要维护。
