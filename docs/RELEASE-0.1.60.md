# Bili-Space 0.1.60

这一版是一次全面优化：更小、更省、更流畅，界面和功能都保持不变。

- 安装包和程序更小：移除了用不到的推理运行库和模型文件，Windows 包不再附带 macOS/Linux 专用文件，程序文件去掉了调试符号。
- 更省 CPU 和内存：顶栏布局和时钟只在有变化时更新，插件计时只在有插件运行时工作，屏幕外一直循环的加载动画会暂停，弹幕和直播聊天不再触发整页扫描。
- 顶栏和首页显示得更快；关闭了 B 站页面用不到的 SmartScreen 信誉查询和表单自动填充分析。
- 首次启动的默认窗口更大，并按屏幕缩放自动调整；退出时会记住窗口大小和位置。
- 移动窗口后，下拉菜单和输入法候选框的位置保持正确。
- 顶栏头像位置微调。
