# Bili-Space 0.1.60

这一版是一次全面性能优化：更小、更快、更省，界面和功能都保持不变。

## 优化幅度（与 0.1.59 对比实测）

| 项目 | 0.1.59 | 0.1.60 | 变化 |
| --- | --- | --- | --- |
| Windows 安装程序 | 58.2 MB | 26.7 MB | 小 54% |
| Windows 压缩包 | 70.8 MB | 35.0 MB | 小 51% |
| macOS 安装包 | 42.7 MB | 15.7 MB | 小 63% |
| Linux 安装包 | 35.2 MB | 10.9 MB | 小 69% |
| 启动后空闲 CPU 占用 | 约 64% 单核 | 约 29% 单核 | 降低约 55% |
| 内存占用 | 约 785 MB | 约 606 MB | 降低约 23% |
| 顶栏可用时间 | 约 7.6 秒 | 约 1.2 秒 | 快约 84% |
| 首页首次显示 | 约 0.5 秒 | 约 0.2 秒 | 快约 60% |
| 弹幕/直播聊天引起的整页扫描 | 每秒最多约 5 次 | 0 次 | 减少 100% |

## 更新内容

- 安装包体积减半：移除了用不到的推理运行库和模型文件，Windows 安装程序从 58.2 MB 减到 26.7 MB（小 54%），macOS 和 Linux 安装包小了六成以上。
- 程序文件去掉调试符号，Windows 包不再附带 macOS/Linux 专用文件。
- 启动后空闲时的 CPU 占用降低约 55%，内存占用降低约 23%。
- 顶栏可用时间从约 7.6 秒缩短到约 1.2 秒（快约 84%），首页首次显示快约 60%。
- 顶栏布局和时钟改为只在有变化时更新，不再定时刷新。
- 插件计时只在有插件运行时工作，没有插件时完全不占用。
- 屏幕外一直循环的加载动画（骨架屏闪光、转圈）会自动暂停，滚动到附近时立即恢复。
- 看视频和直播时，弹幕和聊天消息不再触发整页扫描，播放更省电。
- 关闭了 B 站页面用不到的 SmartScreen 信誉查询和表单自动填充分析，打开页面更快。
- 首次启动的默认窗口更大，并按屏幕缩放自动调整；退出时会记住窗口大小和位置。
- 移动窗口后，下拉菜单和输入法候选框的位置保持正确。
- 插件导入时会正确拒绝带路径的主文件名。
- 顶栏头像位置微调。
