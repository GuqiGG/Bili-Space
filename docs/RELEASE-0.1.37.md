# Bili-Space 0.1.37 · 设置入口修复

- 修复客户端设置齿轮无响应：更新提醒标记与更新操作字段发生冲突，导致点击被误拦截。
- 更新提醒使用独立字段，更新操作只接受明确的动作；保留有更新时的提醒圆点。
- 已验证无更新、发现更新及忽略更新三种状态，设置均能打开，更新按钮仍可正常使用。

- `Bili-Space-0.1.37-Setup.exe`：安装版，Windows 10/11 x64，当前用户安装。
- `Bili-Space-0.1.37-win64.zip`：便携版，解压运行。
