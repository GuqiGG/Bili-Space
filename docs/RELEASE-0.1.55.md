# Bili-Space 0.1.55

这一版带来多开视频：每个视频在客户端里单独打开，窗口右侧有一条视频栏，像浏览器标签一样随时切换。同时放大了小窗口下的顶栏，重做了设置页，并修了一批切换页面时的闪烁问题。

## 多开视频

- **每个视频单独打开**：在首页点视频会新开一个视频页，首页保持不动；已经打开的视频再点会直接切过去，最多同时保留 9 个，超出时关掉最久没看的那个。
- **右侧视频栏**：窗口右侧外面显示正在打开的视频封面，窗口最大化或右边放不下时收进窗口内侧。鼠标放上去图标弹性放大并显示标题，右上角出现关闭按钮。
- **首页按钮**：视频栏最上面是粉色的小电视，点它回首页；在首页时它会自动收起，进视频页时再弹出来。
- **快捷键**：Ctrl+1~9 切换视频，Ctrl+T 回首页，Ctrl+W 关闭当前视频并回到上一个看的视频。
- **省内存**：切走的视频会暂停播放、挂起并降低内存占用；切回来时自动接着播放。
- **加载更顺**：新视频在后台加载，原页面的加载动画一直播放，准备好后再淡入切换，不再闪烁。
- 视频栏在独立线程上运行，页面加载时不会卡顿；关闭视频时图标缩小淡出，其余图标滑动补位。

## 顶栏

- **小窗口下顶栏更大**：窗口越小放大越多，窗口越大加成越少（约 1240px 宽放大 20%，2000px 宽放大 8%）。
- 顶栏缩放不再被网页脚本冲掉，换页时顶栏不会突然变小再变回。
- 当前页的导航字样鼠标放上去会变成刷新按钮；点击分区或首页后要等动画结束、鼠标再动一下才会出现，避免误触。
- 复制链接按钮单击复制、按住拖动可以拖动窗口。
- 展开分区时分区链接和主导航样式一致，中间的链接按钮自动淡出，不再重叠。
- 返回 / 前进按钮的出场、入场动画会在页面显示后播放，能看清楚了。
- 在首页点"首页"不再让 Logo 消失；从视频回首页不会再莫名刷新。

## 设置

- **分区更清楚**：每个分区是一张独立的圆角卡片，展开收起有过渡动画。
- **搜索支持相近词**：比如搜"毛玻璃"能找到磨砂，"小窗"找到画中画，"暗色"找到深色，输入"进条"也能找到进度条。
- **首页每行最少视频数**：设置后窗口窄时至少显示这么多，窗口变宽时仍会自动增加。
- **测试版弹性按钮**：开启后鼠标移到客户端按钮上会轻轻弹一下。

## 磨砂与细节

- 测试版磨砂不再磨砂顶栏，改为磨砂左下角的设置和投稿按钮；修好了磨砂模式下视频卡片层叠的问题。
- 视频页的"首页 / 下载"按钮改为阴影，和标题之间更紧凑。

## 安装与更新

安装版：运行 Setup；便携版：完整解压 ZIP 后运行 Bili-Space.exe。已有版本可在客户端内检查更新、下载并安装重启。登录和设置保存在用户数据目录，升级不会丢。

多开视频与视频栏目前仅 Windows 提供。提供 Windows x64 安装包与便携包、Win7 x64 兼容包、macOS 14+ Universal 包与 Linux DEB。Win7 需要 SP1、UCRT 和 WebView2 109，尚未实机验证；Mac 包未做 Developer ID 公证。
