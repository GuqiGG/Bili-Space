# Bili-Space 0.1.53

这一版有两件事：收藏夹和顶部栏左侧补上了一直缺的动画；个人主页、消息和搜索的官方页面资源也改为从本地读取，打开更快。

## 收藏夹

- **从书签按钮里展开**：面板从书签图标的位置放大、淡入，曲线收得干净，不会回弹过头；关闭时轻轻收回再隐藏，中途反复点击会接着当前状态继续，不会闪。
- **书签变成实心**：面板打开时书签图标填充为主题色，并轻微弹一下，一眼就能看出收藏夹是开着的。
- **加载时显示占位卡片**：读取收藏期间，左侧列表和右侧视频位置显示柔和呼吸的占位块，布局不会跳动；读屏软件仍会读出加载状态。
- **卡片依次浮现**：视频卡片按顺序轻轻上浮出现，加载更多时新的一批同样依次出现；封面加载完成后淡入，不再一块块突然冒出来。
- **选中高亮会滑动**：切换收藏夹时，左侧的选中底色平滑滑到新位置。
- **按压反馈**：收藏夹按钮、文件夹、视频卡片、重新加载与加载更多在按下时都会轻微缩小，关闭按钮悬停时显示圆形底色。

## 顶部栏左侧

- **主导航与分区交替出现**：展开分区时，"首页 / 动态 / 历史"向右淡出，分区从左侧滑入；收起时反过来，不再瞬间消失或出现。
- **视频页的首页按钮**：使用 Windows 窗口按钮时，进入视频页，左侧的"首页"会展开出现，导航里重复的"首页"同时收起；离开视频页时反向收回，不再直接蹦出或消失。
- **跨页面也能接上动画**：客户端会记住上一页的类型，整页重新加载后，顶部栏从上一页的样子过渡到当前页。
- **当前页下划线会移动**：在首页、动态、历史之间切换时，下划线从上一项滑到当前项；从别的页面回来时，下划线从中间展开。
- **返回 / 前进按钮收起**：不需要显示时，按钮会收窄淡出，不再直接消失；变为不可用时透明度平滑过渡。
- **按压反馈**：返回、前进、分区箭头、导航项、首页、消息按钮按下时轻微缩小。
- 搜索面板关闭时也会淡出收回，和打开时的动画对称。

## 加载速度

- **个人主页、消息、搜索的官方资源改为本地读取**：这些页面用到的 B站官方脚本、样式和图标字体随客户端一起打包，打开时直接从本地读取，不再每次从网络下载。资源未变化时命中本地，B站更新后自动回到网络加载。
- **个人主页与消息中心缓存页面**：和首页一样，你自己访问过的个人主页与消息中心页面会在本机按账号单独缓存 24 小时，再次打开更快。搜索结果每次不同，所以搜索页只把资源放到本地，不缓存结果页。

## 无障碍

- 系统开启"减少动态效果"时，以上位移与缩放动画全部关闭，只保留必要的淡入淡出；键盘操作分区时依旧即时切换。

## 安装与更新

安装版：运行 Setup；便携版：完整解压 ZIP 后运行 Bili-Space.exe。已有版本可在客户端内检查更新、下载并安装重启。登录和设置保存在用户数据目录，升级不会丢。

提供 Windows x64 安装包与便携包、Win7 x64 兼容包、macOS 14+ Universal 包与 Linux DEB。Win7 需要 SP1、UCRT 和 WebView2 109，尚未实机验证；Mac 包未做 Developer ID 公证。

## 验证范围

自动化回归 250 项全部通过，Windows 原生客户端本地编译通过；本地资源清单 105 个文件的哈希校验与按账号隔离的页面缓存测试通过。收藏夹与顶部栏动画在浏览器预览中逐帧检查过。
