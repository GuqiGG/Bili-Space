# Bili-Space 0.1.65 · 安卓版 | 你为什么这么做

- 修复：用久了越来越卡，按住音量键要等好几秒才有反应
- 安卓版来了：和电脑一样的界面和增强，在本页下载 APK 安装，之后可以在软件里直接更新
- Linux 和 macOS 版也能在软件里检查、下载并安装更新
- 顶栏新增稍后再看按钮，小闹钟的指针显示真实时间，点一下会转几圈
- 可以选择从稍后再看打开视频时跳到普通视频页
- 拖动搜索框左边缘可以调整宽度，双击恢复默认
- Ctrl+滚轮缩放改为平滑过渡
- 修复：看完视频再搜索时一直转圈，或显示上一次的搜索结果
- 修复：收起弹幕列表后下面空出一大块
- 首页每行视频数跟随窗口真实宽度，最多 7 个
- 搜索结果一出现，顶栏的加载圈就停下
- 顶栏按钮按下时轻轻缩小，鼠标划过时不再抖动 1 像素
- 反馈在主服务器连不上时自动换备用线路，都失败时可以复制内容
- 新增内置插件「悬浮设置面板」（默认关闭），右 Shift 打开
