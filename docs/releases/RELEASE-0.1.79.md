# Bili-Space 0.1.79 · 补帧上线、窗口拖动不卡

- 补帧正式上线：播放器右下角清晰度左边新增「补帧」「超分」按钮，样式和播放器一致；鼠标放上去可以开关、选择最高帧率、超分模式和模型
- 修复：拖动窗口边框改大小很卡——拖动中网页不再逐步重新排版，松手后一次排好
- 修复：全屏播放时底部被 Windows 任务栏挡住
- 首页顶部横幅可以去掉（默认去掉，不留空）
- 首页卡片过滤：可分别隐藏直播、番剧和影视、课程、漫画（设置 → 页面净化）
- 新增「视频坞」开关：关掉后视频直接在当前页播放，视频坞、多视频切换和首页预加载一起关闭
- 首页缩小页面时一行能放更多视频（最多 10 个）
- 左下角设置按钮只在首页显示，平时半透明，不会再完全消失
