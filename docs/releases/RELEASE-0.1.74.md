# Bili-Space 0.1.74 · 全屏一键关视频、下载选清晰度

- 全屏看视频时鼠标移到屏幕最上面，出现「退出全屏 / 关闭视频」
- 下载视频前可以选清晰度
- UP 主更新通知加了关闭按钮和「关闭通知」，全屏时先不弹，退出全屏再弹
- 新设置：首页两边留白（自动 / 宽松 / 适中 / 紧凑 / 最窄）、显示拉黑按钮、自动隐藏左下角按钮
- 首页「换一换」现在整页都会换，不再只换第一行
- 支持导入油猴脚本（按 @match 只在对应页面运行，支持常用 GM_ 函数）
- 新设置「HDR 画质」：默认开，和网页版一样；HDR 视频在显示器上发白时可以关掉
- 测试功能提醒每次启动只弹一次；设置里搜「悬浮视频」「视频坞」能找到官方视频播放样式
- 「分享给朋友」卡片加了「不再显示」
