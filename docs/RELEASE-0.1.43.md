# Bili-Space 0.1.43

- 内置抖音美好体，无需另行安装字体，保留字体开关与原始 OFL 授权。
- 恢复默认设置前新增确认弹窗，支持取消、Esc 与键盘焦点循环。
- 新增设置搜索：支持跨分类、多关键词和中文输入法，点击结果定位原设置；Esc 先清空搜索，再关闭设置。
- 顶部视频链接支持 Shift＋点击复制当前播放时间点，保留分 P；普通点击仍复制原链接。
- 修复任务栏最小化/还原的窗口样式，保留 Windows 系统过渡路径；继续隐藏标题栏，画中画退出后恢复正常窗口样式。
- README 与 GitHub 仓库增加官网入口 https://bili.gvqi.top，移除 README 中的网站部署说明入口。

## 安装与更新

安装版：运行 Setup；便携版：完整解压 ZIP 后运行 Bili-Space.exe。已有 0.1.42 可在客户端检查更新、下载并安装重启。

0.1.38 的旧更新器存在退出竞态；若安装重启失败，请先从托盘退出客户端，再运行本版 Setup 覆盖原目录。登录和设置保存在用户数据目录。

## 验证范围

通过自动化回归、Windows 原生窗口状态与边框命中检查。任务栏动效受 Windows 动画设置及桌面环境影响，不强制修改系统动画开关。
