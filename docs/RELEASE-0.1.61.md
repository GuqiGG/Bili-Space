# Bili-Space 0.1.61

- 字号恢复正常：Windows「设置 → 辅助功能 → 文本大小」重新对页面生效，调大过文字的用户不会再觉得字变小，修改后实时跟随。
- 新增「设置界面字号」拖动条（个性化 → 外观），80%–160% 自由调节，只放大客户端设置窗口。
- 首页的「换一换」回来了：海外网络下不再被直接打开成没有「换一换」的海外版首页。
- 深色模式下全屏时，发弹幕区域恢复为透明蒙版，不再是黑色背板。
- 弹幕设置区域左侧的在线人数与弹幕数不再和弹幕开关重叠。
- 修复偶尔点最大化后，页面没有跟着变大、右侧和下方出现黑边的问题。
- 按钮悬停和按下的过渡更跟手。
- 新增「全屏动画（实验性）」（个性化 → 外观，默认关闭）：进出全屏时视频从原位放大、缩回。
- Linux 和 macOS 版现在会保存观看记录和拉黑设置。
- 在不支持的平台上隐藏超分辨率和补帧选项。
- 移除了一个临时弹窗。
