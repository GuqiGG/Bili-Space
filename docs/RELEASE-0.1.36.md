# Bili-Space 0.1.36

- 新增 Windows Setup 安装版：开始菜单、可选桌面快捷方式与卸载入口；保留便携 ZIP。
- 个性化新增时间显示，位于 Logo 左侧；视频链接排列在时间左侧。
- 画中画新增普通弹幕，窗口大小达到设置的宽度后显示，字号随画面自适应。
- 画中画播放/暂停使用 SVG 切换动画，跟随实际播放状态。
- 修复音量滑条末端拖动、指针取消、静音切换、200% 增益回跳及键盘操作。

## 下载

- `Bili-Space-0.1.36-Setup.exe`：安装版，Windows 10/11 x64，当前用户安装。
- `Bili-Space-0.1.36-win64.zip`：便携版，解压运行。
- `SHA256SUMS.txt`：文件完整性校验。

安装前请从托盘退出旧客户端。安装与卸载均保留已有登录、设置和下载文件。
需要 Microsoft Edge WebView2 Runtime；安装包未内置运行时。安装包暂无代码签名，Windows 可能显示安全提示，请确认来源与 SHA256 后运行。

画中画弹幕支持普通滚动、顶部与底部弹幕；高级/BAS 弹幕暂不支持。弹幕获取受 B站接口与网络状态影响。
