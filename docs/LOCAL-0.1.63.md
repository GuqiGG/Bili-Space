# Bili-Space 0.1.63 · 本地预览（基于 0.1.62）

改动全部在 `assets/enhance.js`，尚未提交。已在 `bc/app` 的 0.1.62 客户端里实机测试（`--diagnostics` 调试端口 9224）。

## 首页

- 隐藏首页右下角的「新版反馈」（`.feedback-btn`）和「客服」（`.customer-service-btn`），只作用于首页。
- 实测：两个按钮的 `display` 都是 `none`。

## 左下角悬浮按钮（投稿 ＋、设置齿轮）

- 原因：毛玻璃模式下通用按钮规则把边框设为透明，浅色主题阴影只有约 9% 不透明度且很散，白色页面上几乎看不见边缘。
- 现在两个按钮始终保留一条细边框和更紧凑的阴影，深色、浅色、毛玻璃模式都生效。

## 窗口按钮离开动画

鼠标移出按钮时播放；每个图标结束时都回到原位，不会跳一下。

| 按钮 | 效果 |
|---|---|
| **×** | 1.35 秒转 3 圈，先快后慢地停下。后面跟着 4 层半透明残影做动态模糊：一开始拖得很长，越转越慢残影越收拢，最后消失。 |
| **□** | 果冻旋转：先冲到约 120°，再弹回 90°（正方形转 90° 看起来和原来一样）；同时整体鼓一下，宽高错拍伸缩，像软方块在晃。 |
| **—** | 被鼠标拽住：鼠标往哪边离开，线就往哪边被拉——往左右离开时靠近鼠标的一端被拉长，往上下离开时中间被拽弯；松开后 Q 弹回去，来回晃几下停住。用 SVG 路径变形做的，是真的弯曲，不是缩放。 |

- 鼠标在按钮上停留不到 0.15 秒就移开，不播动画；只是从按钮上扫过去时保持安静。阈值在 `pointerout` 监听里的 `>=150`。
- 每次鼠标移开都会重新播放，不用等上一次播完；× 会从当前角度接着转，最后仍然停在整圈上，不会跳。
- 只响应鼠标；系统开启「减少动态效果」时不播放。
- 监听挂在头部的 shadow root 上，用会冒泡的 `pointerout`，并判断鼠标已离开整个按钮，按钮被重画后依然有效。不能用捕获阶段的 `pointerleave`：Chromium 的真实鼠标不会把它传到上层，只有脚本模拟的事件会。

## 分区展开 Q 弹动画

- **展开**：分区链接从左边一个接一个弹出。每个从缩小、模糊的状态飞入，冲过头约 6px 再回弹，落定时宽高错拍伸缩，像果冻一样晃两下。
- **收起**：每个分区字先往外蓄力一下，再被「吸」回分区按钮，路上会被拉长；离按钮最近的先走。
- **收起彩蛋（1% 概率）**：随机一个分区字卡住了——别的都走了它还在原地哆嗦、挣扎，然后朝按钮方向被拉长，结果「啪」地弹反方向飞了出去，在外面晃悠一会儿，回过神来再慌忙冲回按钮。全程约 2.3 秒。
- **首页 / 动态 / 历史**：等分区字都收回去之后才出现，不会再和分区字叠在一起（彩蛋时也是等它冲回去以后）。
- **展开按钮的箭头**：旋转时会轻微冲过头再弹回。
- **窄窗口**（分区显示为下拉面板时）：改为从上往下弹入。
- **键盘操作或减少动态效果**：仍然瞬间切换，没有动画。

## 调参位置

- × 的圈数和时长：`WINDOW_LEAVE_MOTION.close` 里的 `turns` 和 `duration`。
- 回弹程度：各处 `springCurve(刚度, 阻尼)` 的第二个参数，数字越小越弹。
- 分区果冻感：`animateCategoryLinks` 里的 `wobble`（`.12`），弹出间隔是 `gap`。
- 彩蛋概率：`animateCategoryLinks` 里的 `Math.random()<.01`；彩蛋的每一段在 `stuckCategoryFrames` 里。
- 「—」被拽的力度：`WINDOW_LEAVE_MOTION.minimize` 里 `shape` 的系数（`2.8` 是拉长，`5.5` 是拽弯）。

## 测试注意

- 头部在单独的页面 `__bili_space_chrome__` 里；内容页里的头部是隐藏的，动画在那里本来就关闭。
- 分区按钮的点击把 `e.detail===0` 当作键盘操作，所以脚本里用 `el.click()` 测不出动画，要派发 `detail:1` 的鼠标点击。
- 头部里还有一组隐藏的红绿灯按钮也带 `data-window`，测试时要用 `.window-actions [data-window=…]` 选右上角那三个。
- 测彩蛋可以临时把 `Math.random` 改成返回 `0.001` 再点收起。
