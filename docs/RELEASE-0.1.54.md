# Bili-Space 0.1.54

这一版让页面切换真正"本地优先"：首页、动态、历史、消息和你的个人主页，切过去就先显示本机保存的页面，内容再从 B站实时加载。另外补上了消息悬停菜单，并修好了搜索框和磨砂效果的几处细节。

## 本地优先

- **切换页面先显示本地页面**：首页、动态、历史、消息中心和个人主页，只要本机保存过，就直接打开本地页面，不再先等网络下载整页；视频列表、消息、评论这些内容仍然从 B站接口实时加载。
- **后台自动更新本地页面**：每次打开页面后，客户端会在空闲时悄悄拉一份最新的官方页面存起来，下次打开就是新的；同一页面 10 分钟内不重复拉取，开启省流量时不拉取。
- **提前准备好常用页面**：打开任意页面后，会在后台依次保存首页、动态、历史、消息中心和你自己的个人主页，第一次切过去也能本地秒开。
- 本地页面按账号分别保存，最长保留 30 天；搜索结果每次都不同，所以仍然只把搜索页的资源放在本地，不缓存结果页。

## 消息悬停菜单

- **鼠标放到消息按钮上，弹出消息分类**：回复我的、@我的、收到的赞、系统消息、我的消息，点哪项直接打开对应页面。菜单内置在客户端里，不需要加载网页。
- **哪类有新消息一眼就能看到**：回复、@、赞显示具体数字；系统消息和我的消息只显示小红点。
- 菜单从按钮下方轻轻落下，离开后自动收起；键盘聚焦消息按钮也能打开，按 Esc 关闭。

## 细节修正

- **搜索框聚焦不再套粗框**：点击搜索框时，外圈那道偏移的粉色粗描边去掉了，改成一条沿圆角的主题色细线。
- **磨砂模式下搜索框有清晰的边缘**：保留一条发丝级描边；搜索按钮不再显示成方块。
- **头像卡片、搜索面板、收藏夹、消息菜单统一磨砂**：开启磨砂后，这些弹出面板都会透出背后模糊的内容。此前搜索面板因为放在同样开启了模糊的搜索框里，看起来是实心的。
- **"换一换"按钮加上圆角**。
- **未读数字真正居中**：消息图标和菜单里的数字按字形的实际高度居中，不再偏上。

## 安装与更新

安装版：运行 Setup；便携版：完整解压 ZIP 后运行 Bili-Space.exe。已有版本可在客户端内检查更新、下载并安装重启。登录和设置保存在用户数据目录，升级不会丢。

提供 Windows x64 安装包与便携包、Win7 x64 兼容包、macOS 14+ Universal 包与 Linux DEB。Win7 需要 SP1、UCRT 和 WebView2 109，尚未实机验证；Mac 包未做 Developer ID 公证。

## 验证范围

自动化回归 256 项全部通过，Windows 原生客户端本地编译通过；本地页面 30 天有效期与按账号隔离的缓存测试通过。消息菜单、搜索框和磨砂效果在浏览器预览中检查过。
