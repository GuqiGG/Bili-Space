# Bili-Space 0.1.47

- 账号入口改为浮动登录面板：点击「登录 B站」不再整页跳到 passport，而是在页面内固定浮出一个面板，随时可关，主界面不会被导航打断。
- 面板内直接呈现官方登录页的全部方式：扫码登录、密码登录、短信登录，以及 Google / Facebook / 微信 / 微博 / QQ 等第三方登录，验证码与加密都交由官方页面处理。
- 面板按内容自适应：官方页是 1100×766 的桌面布局，面板按可用空间等比缩放整页，窄窗口下也不会把密码、短信或其他方式裁掉。
- 登录成功后面板自动收起，顶部头像与账户卡片同步刷新成已登录状态；点「已存账号」页签可以直接切换、添加或移除已保存的账号。
- 面板固定在视口里不随滚动移动，Esc 键和点击面板外部都能关闭；窗口宽度 620 以下依然可用。
- 修正已登录判定：头像地址不可用时，入口仍正确按已登录处理，点击进入个人空间而不是再次弹出登录。

## 安装与更新

安装版：运行 Setup；便携版：完整解压 ZIP 后运行 Bili-Space.exe。已有版本可在客户端内检查更新、下载并安装重启。登录和设置保存在用户数据目录。

## 验证范围

`node --check` 通过，`scripts/build.ps1` 构建通过，dist 产物与源码换行归一后逐字一致。真实 WebView2 内用 `--test` 的 CDP 通道实测：面板为 fixed 定位、不铺满屏、在视口内；扫码二维码、密码登录（可输入账号密码）、短信登录（手机号与验证码输入框）、Google / Facebook / 微信 / 微博 / QQ 均在面板可见范围内；Esc 与点击外部均可关闭；模拟已登录响应后 3 秒内自动收起并标记已登录；640 与 600 宽窗口下面板均在视口 90% 以内且 iframe 完整贴合。证据见 `verification/login-*.json` 与 `verification/login-*.png`。
