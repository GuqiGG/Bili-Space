# Bili-Space 0.1.52

这一版把顶部导航的手感补齐：分区入口会随开关滑入滑出，箭头跟着平滑旋转；前进、后退两个方向都有明确的图标反馈，不再是"点了不知道有没有生效"。

## 顶部导航

- **分区入口滑入滑出**：开关分区栏时，入口按钮按 360ms 的曲线展开或收起，图标同步位移淡入，不再瞬间出现或消失。
- **箭头平滑旋转**：展开了会转 180°，收起转回原角度，同样使用 360ms 曲线，不再生硬跳变。
- **已显示时不重播**：按钮已经在屏幕上时，普通页面切换不会让它重新播一遍入场动画，只有真正的显示/隐藏切换才触发。
- **前进按钮**：除返回外新增前进，两个方向都有对应图标与可用状态。
- **导航反馈**：后退、前进按钮会按当前是否真的能后退/前进显示，不能用时不会假装可点。

## 顺带修正

- 顶部品牌区域在跨域名页面之间切换时保持可见性，不再因为换了站点就整块消失。
- 自动隐藏的品牌名改为向左滑出，不再是直接消失。
- 页面标题与顶部内容做了一次视觉对齐。
- 刷新面板的描边改成阴影。

## 安装与更新

安装版：运行 Setup；便携版：完整解压 ZIP 后运行 Bili-Space.exe。已有版本可在客户端内检查更新、下载并安装重启。登录和设置保存在用户数据目录，升级不会丢。

提供 Windows x64 安装包与便携包、Win7 x64 兼容包、macOS 14+ Universal 包与 Linux DEB。Win7 需要 SP1、UCRT 和 WebView2 109，尚未实机验证；Mac 包未做 Developer ID 公证。macOS/Linux 的平台功能范围见 0.1.50 平台说明，不包含 Windows 专属的原生下载、Mihomo、SMTC 和安装器自动更新。
