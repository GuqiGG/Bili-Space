# Bili-Space 0.1.50

- 新增剪贴板视频提示：检测 BV 号、B站视频链接和 b23.tv 短链接，在右下角显示无边框磨砂卡片，确认后才跳转；可在个性化关闭检测。
- 新增「个性化 → 测试版磨砂」，默认关闭。开启后按钮、投稿、设置入口和首页卡片使用主题与强调色染色的磨砂材质，以柔和阴影分层；顶部栏从上到下渐变透明。
- 修复设置关闭按钮对齐，使用居中 SVG；普通界面移除明显描边并增加柔和阴影及极淡白色高光。
- 首页隐藏返回按钮，其他页面使用居中 SVG；修复收藏封面中 HTTP 地址被丢弃的问题。
- 新增多账号管理；直接挂载官方登录组件，支持深色和官方展示的扫码、密码、短信及第三方登录入口，无登录网页 iframe。
- 提供 Windows x64 安装包与便携包、Windows 7 x64 兼容便携包、macOS 14+ Universal 包（Apple 芯片及 Intel）和 Linux DEB。

Windows 7 包需要 SP1、UCRT（KB2999226 或相应 VC 运行库）和 WebView2 Runtime 109；未经过真实 Win7 机器验收。磨砂使用浏览器支持的滤镜，无滤镜时保留半透明染色和阴影。

macOS 包为临时签名，尚未经过 Developer ID 公证。macOS/Linux 当前提供浏览、收藏、登录和多账号基础功能，不包含 Windows 专属的原生下载队列、Mihomo、SMTC 和安装器自动更新。详见 [平台范围](https://github.com/GuqiGG/Bili-Space/blob/v0.1.50/docs/PLATFORMS-0.1.50.md)。

官方登录入口的真实授权和验证码需要自行完成，测试不提交账号密码或短信。
