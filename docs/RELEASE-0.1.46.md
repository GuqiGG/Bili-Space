# Bili-Space 0.1.46

- 弹幕断档时自动回退原生层，数据恢复后重新接管；距分段结束 30 秒预取下一段、缓存扩到 24 段，跨段不再整屏空白。
- 下载线程上限提升到 128（默认 8），大文件可以开到极限；连接数会按文件大小收敛，避免小文件开过多分段。
- 设置左侧页签支持滚轮滚动并显示细滚动条，页签再多也能看到“关于与更新”。
- 新增本地插件接口：插件目录 + `plugin.json` + 受限 API（样式、存储、事件、播放器状态），设置里可开关、打开目录、重新加载；插件拿不到 native 能力。
- 随包提供插件文档与示例插件。

## 安装与更新

安装版：运行 Setup；便携版：完整解压 ZIP 后运行 Bili-Space.exe。已有版本可在客户端内检查更新、下载并安装重启。

0.1.38 的旧更新器存在退出竞态；若安装重启失败，请先从托盘退出客户端，再运行本版 Setup 覆盖原目录。登录和设置保存在用户数据目录。

## 验证范围

通过 227 项自动化回归（含插件宿主与弹幕断档回退）、社区状态与 Windows 媒体集成的原生测试；构建产物内含插件宿主与新弹幕接管逻辑。
