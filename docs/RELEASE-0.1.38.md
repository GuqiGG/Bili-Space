# Bili-Space 0.1.38

## 软件内更新

- 设置 → 关于中检查、下载更新，显示下载进度并校验 SHA256。
- 下载完成后点击「安装并重启」，客户端自行退出、静默安装到原目录并重新启动；不再手动解压替换。
- 安装前再次校验文件大小和 SHA256，阻止被修改的安装包。
- 保留登录、个性化设置和下载内容；安装失败会记录日志，安装器结束后尝试恢复启动。
- 更新站不可用时回退 GitHub；同版本保留网站的强制更新策略，普通更新仍可以忽略。

## 从旧版升级

0.1.37 及更早版本没有自动安装功能，首次请运行本版本 Setup；0.1.38 起可使用软件内安装更新。

Windows 10 / 11 x64，需要 WebView2 Runtime。超分和补帧仍为实验功能。
