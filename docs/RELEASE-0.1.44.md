# Bili-Space 0.1.44

- 内置下载器改为 4 路分段并发与断点续传，大文件下载明显提速；支持下载队列、多 P 与合集选择、暂停/继续/重试。
- 设置新增拉黑管理，可查看官方黑名单并取消拉黑；搜索历史支持折叠与“更多历史”，输入时上下键直接选择官方联想。
- 弹幕增强支持重复弹幕合并为“原文 ×N”、洪峰计数角标、按滚动/顶部/底部过滤显示区域、字号缩放、正则关键词与无意义弹幕过滤，主窗口与画中画一致。
- 接入 Windows 系统媒体中心（SMTC）与任务栏缩略图按钮，支持播放/上一集/下一集。
- 下载速度按断点续传后的实际新增字节计算，不再把已下载部分算进速率。

## 安装与更新

安装版：运行 Setup；便携版：完整解压 ZIP 后运行 Bili-Space.exe。已有版本可在客户端内检查更新、下载并安装重启。

0.1.38 的旧更新器存在退出竞态；若安装重启失败，请先从托盘退出客户端，再运行本版 Setup 覆盖原目录。登录和设置保存在用户数据目录。

## 验证范围

通过 219 项自动化回归、下载器 22 项原生 HTTP 检查、社区状态与 Windows 媒体集成的原生测试。下载速度为真实 B 站 CDN 实测（49 MiB 文件：单连接约 58 秒，四连接 4.5–6.1 秒），实际速度仍受 CDN 节点与网络环境影响。
